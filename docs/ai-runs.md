### AI の判定（ゲート2の判断のときの決まり。`src/resolve/ai.ts`・`src/report/ai.ts`）

- ルールで決まらなかった枠を、Claude Code のセッションで判定する。**人が起動するコマンドでだけ入れる**（定期実行のジョブからは呼ばない。有料APIを使わない）
- 見るもの: タイトル・概要欄（定型文を除く）・切り出した区間・**サムネイル（画像を直接見る。絵柄で作品が分かる）**・外部作品DBの照会（`lookup`）
- 判定は `ai_decisions` に1枠1行（取り消しは `revoked_at`）。status（identified / not_a_work / unidentifiable / hold）・作品（外部DBのID）・
  **確度（high / medium / low。low はサイトに出さない）**・見たもの・理由・モデル・バッチ・1枠の時間
- **確定**: 取り消されていない判定（hold 以外）の枠は resolve の対象から外し、最後に判定を入れ直す。ルールを直して `resolve --all` しても上書きしない
- 迷ったら hold（埋めることが目的ではない）。hold の枠は次の ai:queue に出さない
- 同じ誤りを AI が繰り返し直しているなら、ルールにする
- サムネイルは判定のためだけにローカルへ一時的に落とす（data/ai/<batch>/thumbs。サイトには使わない。判定が済んだら消す）
- 判定のファイル（decisions.json）と根拠の一覧はメン限枠の概要欄の内容を含みうるので公開しない
